muzika - soundcloud для рабочего стола

СБОРКА / ОБНОВЛЕНИЕ
  1. выйди из плеера: правый клик по иконке в трее -> exit.
  2. распакуй архив поверх старой папки (lib\ с sdk уже скачан).
  3. запусти build.bat - соберётся muzika.exe и сразу откроется.
  всё твоё лежит в muzika_data рядом с exe: вход в soundcloud, статистика, настройки, кэш.
  при обновлении поверх папки ничего не теряется и логиниться заново не надо.
  переносишь в новую папку - копируй muzika_data целиком.

НАВИГАЦИЯ
  <  (слева от логотипа) - назад, туда же и в то же место списка.
     ещё: боковая кнопка мыши, alt + стрелка влево, backspace.
  now playing - обложка, визуализатор, up next, инфа о треке с soundcloud.
  library     - твои лайки, плейлисты и лента на soundcloud. filter - быстрый фильтр по списку,
                play - включить весь список.
  find        - поиск по soundcloud или ссылка на трек / плейлист / профиль / лайки (ник/likes).
                последние запросы сохраняются под строкой поиска.
  profile     - твой профиль на soundcloud: баннер, подписчики, треки, лайки, плейлисты, репосты.
  stats       - сколько ты слушал: минуты по дням и часам, топ треков и артистов, серии.
  about       - про плеер.
  шестерня    - настройки: аккаунт soundcloud, визуализатор, тема, переходы, стекло,
                зерно, кэш, discord статус, цвет обложек.
  link soundcloud (справа сверху) - вход в аккаунт. после входа там твой ник, клик - профиль.

  клик по треку - играть (очередь = этот список). клик по имени артиста - его профиль.
  клик по плейлисту - страница плейлиста. сердечко - лайк на soundcloud.
  сердечко в нижней панели - лайк того, что играет сейчас. eq - эквалайзер.

ИГРЫ И НАГРУЗКА
  крестик прячет в трей, музыка играет. в трее и поверх игры ничего не рисуется.
  мультимедийные клавиши работают из игры. следующие два трека подгружаются заранее.

КЛАВИШИ
  space - play/pause     n / p - следующий / предыдущий
  <- / -> - перемотка    up / down - громкость
  l - library   f - find   t - stats   backspace - назад
  s - shuffle   r - repeat

ЕСЛИ ЧТО-ТО НЕ ТАК
  трек не играет - смотри muzika_data\log.txt и скинь его.
  "webview2 didn't start" - поставь microsoft edge webview2 runtime:
    https://go.microsoft.com/fwlink/p/?LinkId=2124703
  ошибки сборки - скрин окна build.bat.
