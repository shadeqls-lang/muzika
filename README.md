# muzika

![muzika](https://github.com/shadeqls-lang/muzika/blob/main/muzika.png?raw=true)

> **beta** — muzika is still in beta. expect bugs and rough edges. it will keep getting updates.

a lightweight soundcloud desktop client for windows. it's a standalone `.exe`, not a browser tab, so you can keep music on while gaming without your browser eating your ram.

---

## features

- **library**: your soundcloud likes, right on the main screen
- **find**: search soundcloud without opening a browser
- **profile**: your soundcloud account inside the app
- **stats**: how many minutes you've listened and what you play most
- **link soundcloud**: log in with your account
- **tray**: minimize to the system tray, music keeps playing
- **crossfade**: smooth transitions and minimal gaps between tracks
- **design**: dark liquid-glass style, sf pro display, all lowercase, no white title bar

## planned

- equalizer
- themes
- uploading your own tracks
- more ui and ux polish

## install

1. download the latest release
2. run `muzika.exe`
3. press **link soundcloud** and log in

### build from source

run `build.bat`. it produces `muzika.exe`.
